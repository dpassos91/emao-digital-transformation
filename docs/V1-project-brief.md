# V1 Project Brief

## Objective
Deliver a clear, responsive and secure public website for EMAO that explains the educational offer and turns interest into structured trial-lesson requests.

## Users
Families, adult learners and students preparing for specialised music education.

## V1 scope
Information architecture, core institutional pages, pricing, privacy information, responsive navigation, a validated enquiry form, secure database persistence and transactional email notifications.

## Delivery
The project moved through discovery, scope definition, content and UX, implementation, preview testing, stakeholder feedback, security review, production release and end-to-end validation.

## Success criteria
The site is usable across devices, information is easy to find, the form handles valid and invalid submissions correctly, requests persist securely, emails are delivered and no production secrets are committed.
